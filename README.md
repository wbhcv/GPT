# 云朵冒险 · Cloudhop

原创浏览器横版平台游戏，包含经典跑跳、水下游泳、苔角兽骑乘和三关逐步加难的路线。角色、Canvas 插画、旋律和音效均为原创，无外部素材或联网依赖。

## 立即试玩

下载仓库中的 **[play.html](play.html)**，用浏览器打开，再点「开始冒险」。这是完整单文件，离线也能运行。`dist/cloudhop.html` 为相同内容的第二份打包产物，两者都纳入 Git。

手机请使用能运行本地 HTML 的浏览器打开文件；iPhone 的文件预览可能不会执行 JavaScript，可在已托管的网页中游玩。本仓库中的文件可部署到任意静态网站服务。仓库地址不等同于已上线的网站。

## 开发

Node.js 20+，无需安装依赖、API 密钥或数据库。

```bash
npm run check
npm test
npm run build
npm start
```

开发服务器监听 `0.0.0.0:3000`；也可设置 `PORT`。源码使用 ES 模块，应通过服务器打开；`play.html` 可直接离线打开。修改源码后运行 `npm run build`，并将源码、测试、`play.html`、`dist/cloudhop.html` 一起提交。

## 操作

| 操作 | 键盘 | 手机 / 标准手柄 |
| --- | --- | --- |
| 左右移动 | ← → / A D | 方向按钮 / 左摇杆或十字键 |
| 跳跃、划水 | 空格 / ↑ / W / Z / K | ↑ 按钮 / A |
| 奔跑与攻击 | 按住 X / J / Shift | 跑 / 攻击 / B、X 或 RB |
| 下潜、蹲下、进入水道与水管 | ↓ / S | ↓ 按钮 / 向下 |
| 骑乘或下骑 | E / L | 骑乘按钮 / Y |
| 暂停 / 继续 | P / Esc | 工具栏 / Start |
| 重玩本关 | R | 工具栏重玩按钮 |
| 开始、重试、下一关 | Enter | 界面按钮 / A |

轻点小跳、长按高跳；奔跑充分加速后跳得更高、更远。地面有加速、摩擦与反向刹车，空中松方向保留惯性。110 毫秒离台宽限与 130 毫秒落地前按键缓冲帮助衔接跳跃。物理固定 120Hz。手机支持多指操作、按住后滑动换键、横竖屏和全屏退出按钮。

## 玩法

- 三个世界：晴风草甸（4300 像素）、暮色峡谷（4700）、星光高地（5820，含守关场）。村落、水道、风车、遗迹、瀑布、水车和星夜要塞各有场景。窄高台、宽断崖、地空夹击逐关加难。
- 成长蘑菇、火焰花、无敌星星、生命叶片。长大后能顶碎砖块，受伤先变小；星星无敌 10 秒，无法抵挡深谷。火球弹跳并有冷却、数量限制；水下改为气泡弹。
- 巡逻怪、飞怪、龟壳小龟和水管植物。踩龟缩壳，侧碰踢出，再踩停壳；壳能伤敌也会反弹伤人。植物和游鱼不能踩。
- 连踩和龟壳连击奖励逐次提升：100、200、400、800、1000、2000、4000、8000 分，第九次起加命。金币每枚 10 分，每 100 枚加一颗心。顶砖也能击敌，多金币砖可顶 8 次。
- 隐藏奖励方块、弹簧、移动平台、尖刺、矮洞和阶梯。碎裂平台踩下约 0.6–0.8 秒后崩塌，3 秒后恢复；复原时不会出现在玩家体内。喷火口有 0.65 秒预警。暂停会冻结机关和角色。
- 每关两枚高空徽章、一枚地下宝库徽章，各 +300 分。站上有箭头的水管按 ↓ 进入宝库，右侧出口水管按 ↓ 返回。
- 每关开场蓝色水道口按 ↓ 进入蓝湾。跳跃上浮、↓ 下潜，存在阻力、浮力和顺逆流；有游鱼、珊瑚尖刺、25 金币和一颗独立宝珠（+400 分），右侧水管返回。无需收集所有奖励即可过关，无氧气倒计时。
- 开场和复活点后有苔角兽。靠近按 E 骑乘，跑得更快、长按跳跃可短暂悬停，落地恢复一次。攻击变为伸舌吞敌换金币，不能穿墙。E 跳离坐骑。一般受击先分离，保留自身能力和生命；等受惊伙伴停下可追回重骑。进入水道或水管会在陆地留下坐骑。
- 第三关最终守卫：巡逻、蓄力、喷低空火球和恢复循环。三次跳踩或六次有效火球击退；受击有冷却。门前有独立复活点和火焰花，失败后重新补给。击退后才可穿过星门触旗。
- 新开关卡 3 心、240 秒；中途小旗是复活点。奖励不会因死亡或重访重新生成。旗杆高度额外加分，播放降旗和走向城堡演出，再结算时间和生命奖励。
- 下一关继承生命、金币、分数与变身，手动选关或重玩重置本关挑战。最佳成绩、徽章与声音设置保存在浏览器；关闭页面不保存正在进行的关卡。
- 各世界、地下、水下、无敌、守关战有原创音乐。60 秒时加快节奏，动作有独立音效；「怎么玩」可调音量、独立音乐、自动奔跑和可选触感反馈。

## 保存与恢复

`play.html` 和 `dist/cloudhop.html` 刻意不加入忽略列表。源码、测试、构建脚本和离线包均应提交并推送到 GitHub，避免只存在临时云目录。

新云环境使用现有检出，不另建 worktree。进程不会随快照保留，先执行检查与测试，再运行 `npm start`。环境设置中的启动说明只保存流程，不等于代码已推送或网站已发布。

## 本次验证（2.0）

- `npm test`：41 项引擎与玩法测试，包括三关完整主线通关、最终守卫、三条蓝湾路线、物理手感、奖励持久性和上下骑。
- `npm run check`：所有 JavaScript / 构建 / 服务脚本语法检查。
- 可选浏览器集成：开发环境已提供 Python Playwright 与 `/usr/bin/chromium` 时，先运行 `npm start`，再运行 `python tests/browser-smoke.py` 与 `python tests/gamepad-smoke.py`。普通游玩和构建不需要 Playwright。
- 浏览器检查通过真实键盘完成三关与三条水下支线，验证过关继承、成绩保存、水下音乐、音效输出和静音；用未修改的单文件在断网的手机环境中验证多指骑乘跑跳、游泳下潜、暂停、全屏退出、320 / 390 像素按键不重叠。标准手柄使用输入模拟器验证，未宣称实体手柄实机测试。
- `npm run build` 可重复生成相同内容；`play.html`、`dist/cloudhop.html` 与服务返回的文件校验值一致，成品中不包含测试控制器或观察代码。
